# Vinted bot comparison evidence

Last re-checked: **1 October 2026**.

This file is the evidence log for `/vinted-bot-comparison` and `/fr/comparatif-bot-vinted`.
Do not advance the checked date without reopening the source pages. A vendor claim is not an independent benchmark.

## SNYPD — product facts used

Verified from the SNYPD repo/product copy, plus owner-confirmed behaviour where noted:

- Free: 1 active Vinted search, no card, no time limit; it runs while the dashboard is open.
- **Owner-confirmed 2026-10-01:** there is no cap on matching alerts/notifications, including on Free.
- Search setup uses the Vinted search URL the user creates with Vinted filters.
- Checks are adaptive: about 30 seconds to 5 minutes. Same speed logic on every plan.
- Paid plans keep monitoring 24/7 with the dashboard closed.
- SNYPD never asks for a Vinted login and does not buy, make offers or message sellers.
- Pro/Elite include Market Report: typical Vinted asking price by condition.
- Push goes to phone/computer plus the SNYPD dashboard; iPhone web push requires the Home Screen PWA.

### Claims we deliberately do NOT make

- `ban-proof`, `no bans`, `100% safe`, or `approved/allowed by Vinted`
- fastest / instant / sub-second SNYPD alerts
- that Market Report is unique to the entire competitor set
- a support response-time SLA
- testimonials, customer counts or ratings that SNYPD does not have

## Telvin Bot

Source checked: https://www.telvin-bot.com/en/vinted-alerts/

Current public page says:
- Free: €0, 1 **keyword** alert, 100 notifications.
- Starter: €4.90, 2 keyword alerts, unlimited notifications, vendor-claimed 750 ms.
- Premium: €8.90, 5 **URL filter** alerts, unlimited notifications, vendor-claimed 750 ms.
- Pro: €14.90, 10 URL filter alerts, unlimited notifications, vendor-claimed 750 ms.
- Delivery: Telegram.
- The site describes the product as notification-only / no automated purchasing.

Important: do not dismiss Telvin based on social follower count. Its own site currently claims 1,200+ members and 3.8M+ notifications; those are vendor claims, not independently verified by SNYPD.

## Crazed

Source checked: https://crazed.fr/

Current public page says:
- Free: up to 3 alerts, platform notifications, refresh every 30 seconds, up to 30 items/day.
- Premium €4.99 and Crazy €9.99 are displayed as **coming soon** on the current page.
- Premium lists 10-second refresh / 300 items/day.
- Crazy lists push, offline alerts and `real time` refresh.

Do not write the paid plans as currently available unless the site changes.

## MarktAlert

Source checked: https://marktalert.nl/pricing

Current pricing page says:
- Free: €0, 2 active alerts, 15-minute checks.
- Plus: €6.95, 5 alerts, 5-minute checks.
- Pro: €10.95, 10+ alerts, 3-minute checks.
- Covers Marktplaats, 2dehands and Vinted.
- Telegram, mobile push and dashboard are listed; the page/FAQ also mentions email/webhook.

The same pricing page currently conflicts with itself about free-alert validity (14 days in the plan block vs 3 days in its FAQ text). The SNYPD comparison therefore omits that expiry claim.

## V-Tools

Source checked: https://www.v-tools.com/

Use the official `.com` site. **Do not use `v-tools.eu` as vendor evidence.**

Current public page says:
- Performance: €29.99/month.

The site has changed plan/account-count copy over time, so re-check before publishing specific account counts.

## Editorial rule for “better” claims

Use **specific fit statements**, not universal rankings.

Supported examples:
- SNYPD Free has no notification cap; Telvin Free is capped at 100 and Crazed Free at 30 items/day.
- SNYPD keeps monitoring separate from the customer's Vinted login and performs no buying/account actions; Souk/V-Tools/Resell Reserve sell buying automation that uses connected account functionality.
- SNYPD Pro/Elite add Vinted asking-price research by condition; do not say no competitor has research/analytics.
- Telvin is cheaper and claims lower latency; MarktAlert covers more marketplaces; automation suites offer features SNYPD intentionally does not.

The page should explain those trade-offs openly. Credibility is part of the conversion strategy.
