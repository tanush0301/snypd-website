Free option 1: Vinted’s own saved searches

Saving a search on Vinted costs nothing. You get a “+N” counter next to the saved search, counting new items since you last looked, and no push notification for new results. How it works in detail: Vinted saved searches.

Good if you open Vinted several times a day anyway. Not enough if you want to hear about a new listing while you are away from the app.

Free option 2: open-source scripts you host yourself

Some open-source projects check Vinted searches and post new listings to a chat app. The software is free; running it is your job:

  • A server or a computer that stays on: the script stops when the machine does.
  • Tokens and setup: usually a bot token for the chat app it posts to, plus configuration files.
  • Updates: when Vinted changes something, the script can stop working until someone fixes it, and that someone may be you.

Good if you like running your own tools. Not a fit if you want something that works without upkeep.

Which free option fits you

  • You check Vinted often and want nothing extra: saved searches.
  • You can run and maintain a server: an open-source script.
